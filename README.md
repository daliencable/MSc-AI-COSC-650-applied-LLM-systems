# MSc-AI-COSC-650-applied-LLM-systems-

This is my repository for COSC 650: Applied LLM Systems, an 8-week graduate course at Maryville University where I'm learning to build with large language models from the ground up, from how tokenization works to fine-tuning and evaluation.

## Why This Repo Exists

I'm using this space to track my work week by week: notebooks, notes, experiments, and eventually a final project. It's part coursework log, part portfolio & a record of what I built and what I learned along the way. If you're a classmate, recruiter, or just curious, everything here should make sense without extra context.

## What We're Covering

Over the 8 weeks, the course moves through tokenization, transformer architecture, prompt engineering, function calling, retrieval-augmented generation, fine-tuning, and evaluation. I'll be adding to this repo as each topic builds on the last.

## How It's Organized

- `week-01/` through `week-08/` will contain weekly assignments and/or notebooks
- `notes/` my research notes and reading annotations
- `practice/` will be used for testing ideas before adding to assignments & projects
- `project/`  will focus on code and documentation for my final project
- `CLAUDE.md` contains instructions for AI coding assistants working in this repo
- `README.md` this file

## Tools I'm Using

- Python 3.11+
- Jupyter, both locally and in Google Colab
- `tiktoken` for tokenization experiments
- OpenAI and Anthropic SDKs, depending on the assignment

## Where Things Stand

I'll keep this updated as the course progresses; check the most recent `week-XX/` folder for my latest work.
